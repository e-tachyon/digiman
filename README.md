# Digiman
### Author: Evan Gilbert
### Github: e-tachyon

## Description
Digiman is a lightweight digital music player allowing you to play, skip, and add songs. It uses miniaudio for playback, sqlite3 for a DB and TagLib to get song information. Currently under Development, but planned to be a full feature music player with a TUI. 

## Video
[![Digiman Demo](https://img.youtube.com/vi/v7DwfnW6GrQ/maxresdefault.jpg)](https://youtu.be/v7DwfnW6GrQ)


## Current Features
- Play/Pause
- Volume Control
- Add Song
- Skip
- Simple SQL DB
- Song Queue

## Planned Features
- Create and Delete Playlists
- Shuffle Play
- TUI (notcurses)
- Add Full Directories
- Playback Speed
